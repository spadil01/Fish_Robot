Fish grid world: learning from experience

The fish starts on a blank grid. Using the Bellman equation, each square’s value is built from the reward for a move plus the discounted value of the square that move leads to, until every square knows which way leads to the ocean and which to fire. Change the rewards, the discount or the layout and watch the values reshape.
